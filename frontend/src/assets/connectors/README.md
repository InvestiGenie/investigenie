# Connector icon assets

Elasticsearch, ClickHouse, Google BigQuery, Prometheus, and VictoriaMetrics use SVG marks from [Simple Icons](https://github.com/simple-icons/simple-icons), licensed CC0 1.0. Trademark rights remain with their respective owners.

Grafana Loki uses `logo.png` from the [Grafana Loki repository](https://github.com/grafana/loki/blob/main/docs/sources/logo.png). Grafana Mimir uses `images/logo.png` from the [Grafana Mimir repository](https://github.com/grafana/mimir/blob/main/images/logo.png), downscaled from 750×534 to 256×182 pixels. VictoriaLogs uses `favicon.svg` from the [VictoriaLogs repository](https://github.com/VictoriaMetrics/VictoriaLogs/blob/master/app/vmui/packages/vmui/assets/favicon.svg).

These marks identify supported data sources; they do not imply endorsement or affiliation.
